SmartMarket API Online

SmartMarket Backend

Java Servlets (Tomcat 9) connected to Oracle Database (XE)

Available REST Endpoints
POST /api/auth/register User Registration
POST /api/auth/login User Login
GET /api/journal/notes Get Research Notes
POST /api/journal/notes Create Note
DELETE /api/journal/notes Delete Note
GET /api/alerts/list Get Price Alerts
POST /api/alerts/list Create Price Alert
